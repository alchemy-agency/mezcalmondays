# eatdanville.com

Directory and destination site for the Danville Dining District ("South of Hartz"): Rancho Cantina, Incontro Ristorante, Kaia's Island Kitchen & Tiki Bar and Danville Harvest on the corner of Hartz Ave and Church St, downtown Danville, CA.

## Stack
- Static site generated by Node (`scripts/build.mjs`) from `data/*.json` and templates in `scripts/templates/`.
- Native CSS with design tokens (`src/css/`), self-hosted fonts, GSAP + ScrollTrigger and Leaflet vendored in `src/vendor/`.
- Vanilla JS modules in `src/js/`: `hours` (live status), `theme` (After Dark), `nav`, `search` (predictive search + on-device learning), `map` (Leaflet), `planner` (two-stop itinerary), `motion` (GSAP), `app` (glue, forms, drawer).
- `api/submit.php` stores industry and partner form submissions outside the web root (`~/www/eatdanville.com/private/`) and can email a notification (set `$NOTIFY_EMAIL`).
- Design contract: `DESIGN.md`. Data schema: `data/schema.md`. JS contracts: `src/js/CONTRACTS.md`.

## Commands
```bash
npm install                      # once
node scripts/build.mjs           # build -> dist/
python -m http.server 4173 -d dist   # preview at http://127.0.0.1:4173
bash scripts/deploy.sh           # build + upload to SiteGround over SSH
```

## Editing content
- Restaurants: `data/restaurants.json` (hours are 24h "HH:MM"; `bar_hours` when the bar outlives the kitchen; `nightcap` drives After Dark; `industry.text` shows on the Industry page once a partner confirms a perk).
- Categories (the 10 search tiles): `data/categories.json`.
- District, parking, landmarks, events, media, chamber, sponsor slots: `data/district.json` (`sponsors[]` renders placements when filled).
- Hero art: `data/hero.json` (background photo, cutout PNGs, After Dark band photo).

## Images
- `scripts/images.py fetch <manifest>` downloads restaurant photos; `cutout` runs rembg for hero cutouts; `web` resizes for the web; `og` makes the share image.
- Google Flow generation runs through the `google-flow-mcp` server (`scripts/flow-mcp.mjs call|batch`, jobs in `scripts/flow-jobs.json`); outputs land in `../google-flow-mcp/outputs/images/`.

## Deploy target
SiteGround shared hosting, web root `~/www/eatdanville.com/public_html/`. `.htaccess` (from `public/`) forces HTTPS and non-www, sets caching and security headers.
