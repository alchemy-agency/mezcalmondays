# mezcal-monday.com

The Mezcal Monday directory: bars and restaurants that pour mezcal, Monday specials, a map finder, where to buy and recipes. Sponsor placements run BNAAA Mezcal by default.

## Stack
- Static site generated by Node (`scripts/build.mjs`) from `data/*.json` and templates in `scripts/templates/`. Output in `dist/`.
- Native CSS with tokens (`src/css/`), self-hosted Archivo and Geist, GSAP + ScrollTrigger, Leaflet + markercluster vendored in `src/vendor/`.
- Vanilla JS in `src/js/`: `theme`, `nav`, `search` (predictive), `map` (Leaflet clusters), `finder` (filters, near me, URL state), `motion` (GSAP hero), `app` (forms, share, reveals, toast).
- `api/submit.php` stores form submissions outside the web root (`~/www/mezcal-monday.com/private/`) and emails when `MM_NOTIFY_EMAIL` is set.

## Commands
```bash
npm install
node scripts/build.mjs                 # build -> dist/
python3 -m http.server 4174 -d dist    # preview at http://127.0.0.1:4174
node scripts/shot.mjs                  # QA screenshots + console errors into qa/ (needs playwright)
node scripts/fetch-fonts.mjs           # refresh self-hosted fonts
```

## Deploy
`.github/workflows/deploy-mezcal-monday.yml` builds and uploads `dist/` to SiteGround over SSH on every push to `main` that touches `mezcalmonday/`. Repository secrets: `SG_HOST`, `SG_USER`, `SG_SSH_KEY`, optional `SG_SSH_PASSPHRASE`, `SG_PORT` (18765), `SG_REMOTE_PATH` (`www/mezcal-monday.com/public_html`).

## Content
- Bars: `data/venues.json`. Stores: `data/stores.json`. Online: `data/online.json`. Schema in `data/schema.md`.
- Regions and site settings: `data/site.json`. Recipes: `data/recipes.json`. Ad placements: `data/ads.json`. Sponsor slots: `data/sponsors.json`.
- BNAAA partner pages and brand images: run the "Harvest BNAAA partner pages" workflow from the Actions tab. It commits `data/bnaaa-pages/` and `src/assets/img/brand/`; the build picks them up automatically (logo in the featured panel, cocktail photos on recipes, `bnaaa_page` on venues).
- Map tiles: OpenStreetMap by default. Paste a CARTO basemaps key into `data/site.json` `map_tiles.carto_key` for light/dark CARTO tiles.
